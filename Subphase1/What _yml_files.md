# YML file
```text
YAML:-Yet Another Markup Language

A YAML file is a plain text file used to define settings, workflows, environments, and system configurations in modern software development.

A YAML file stores structured data using key-value pairs, lists, and nested objects without complex syntax. 

YAML is a markup-like format that organizes data through indentation instead of brackets and braces.

We use a .yml file whenever we need to store configuration, settings, or instructions for a tool, application, or service.
```
