# Fetch Latest Updates from GitHub

```text
git fetch
```

# Switch to Shared Branch

```text 
git checkout ai-service/Subphase1
```

# Check current branch

```text
git branch
```

# Pull Latest Code
Always do this before starting work:

```text
git pull origin ai-service/Subphase1
```
